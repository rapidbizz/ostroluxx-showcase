# Ostroluxx

> Lighting brand website — client project designed by RapidBizz.

Ostroluxx is a lighting brand. RapidBizz designed and built its final client website: a static, SEO-focused site with a full product catalogue, 3D models and product datasheets.

## What was built

- **Website** — static HTML site: home, products, about, careers, catalogues, contact, lighting guide, our projects, technology, support, terms, privacy
- **Products** — product catalogue with model pages (including Elantra decorative wall lamps and lights), product data, PDFs and 3D models
- **SEO** — robots.txt, sitemap, SEO implementation guide, audit report, Search Console setup

## Demo

The `demo/` folder holds small, self-contained examples — a product card (HTML), a filter (JavaScript) and a stylesheet (CSS). They are illustrative examples only, not the client website code.
